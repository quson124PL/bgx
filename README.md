# BGX - BootGraphics image format
Used for an osdev project
<hr>

# Features:
- Uses indexed palettes
- 1,2,4,8 bit per pixel raw encoding.
- (WIP) Per-byte RLE
- Supports 32-bit RGBA, (WIP) 6-bit VGA DAC and EGA Attribute colors for the palette.
